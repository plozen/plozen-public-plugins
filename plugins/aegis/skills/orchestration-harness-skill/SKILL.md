# Aegis 오케스트레이션 하네스

## 핵심 계약

Aegis 전달 작업은 아래 흐름을 기본으로 한다.

```text
Brainstorming -> 라우팅 -> 작업 트리 -> 위임 -> 리뷰 -> QA -> 커밋 -> 브랜치 푸시 -> PR -> 팀장 확인 -> 병합/최종 푸시 -> 정리 -> 보고
```

팀장은 실행자가 아니라 라우터, 검증자, 통합자다. 실행은 가능한 역할 에이전트나 독립 실행 컨텍스트가 맡는다. 최종 저장소 통합, 병합, 최종 푸시, 깨끗한 작업 트리 정리는 팀장이 책임진다.

Brainstorming 단계는 `brainstorming-skill`을 사용해 설계 승인까지 완료한다.

Aegis/PLOZEN 플러그인 저장소 변경은 작은 수정처럼 보여도 PR 흐름이 기본이다. 스킬 추가/수정/삭제, 플러그인 메타데이터, 마켓플레이스 매니페스트, README, 하네스 문서 변경은 작업 트리와 브랜치에서만 수행한다.
